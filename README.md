## 🌐 Como Publicar o Site

Este site foi construído com tecnologias web limpas e universais (HTML5, CSS3 moderno, Vanilla JavaScript e SVGs vetoriais). Você pode publicá-lo em qualquer hospedagem:

* **GitHub Pages:** Suba os arquivos para um repositório GitHub e ative o GitHub Pages nas configurações.
* **Vercel / Netlify:** Basta arrastar a pasta do projeto para o painel do Vercel ou Netlify para publicação instantânea com SSL gratuito.
* **Hospedagem Tradicional (Hostinger, cPanel, Locaweb):** Copie todos os arquivos da pasta para a pasta `public_html` da sua hospedagem.
* **Execução Local:** Basta dar um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador.
